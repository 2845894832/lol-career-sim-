第 2 课 · 间距与分组

挤，是因为东西没分组

你圈的那一行是：体力 · 段位（第几名）· 金钱 · 伤病 · 教练信任。 五件事排成一条，中间只隔 14px。手指没碰到它，眼睛先放弃了。

你的直觉是「把间距加大」。这是最常见的错答案——加完你会发现它只是变长了，还是读不出来。

这一课只有一条规则：先分组，再加间距。同一组内的东西用 4–8px，组与组之间用 16–24px。间距不是装饰，它是「这些是一伙的」这句话。

五件事，其实是三组

组包含为什么它们是一伙的
本钱体力、伤病都是「这周还能不能打」
处境段位、教练信任都是「别人怎么看你」
身家金钱单独一个数，不是状态，是资源

分组不是排版爱好，是玩法结构：本钱每结周回满，处境缓慢变，身家只增不减。三者的节奏完全不同，混成一行就等于说它们一样。

拖一下，看间距到底在做什么

体力 60/100 段位 大师 第 6929 名 金钱 0 伤病 0/3 教练信任 50

滑杆只改组内间距。分组按钮才会真正把它们拉开——注意变化发生在哪几个位置。

三个数字

关系用多少一句话
同一组内4 / 8贴着，但别粘住
组与组之间16 / 24至少是组内的两倍，否则看不出分组
整块与整块24 / 32数值区 ↔ 行动区 ↔ 按钮区

全部取 4 的倍数。理由很实用：改一个数的时候，别的不会连锁抖动。

两道题

  1. 组内间距从 8 加到 20，但组间还是 24。会发生什么？
    分组消失了。间距的意义是对比——组间不明显大于组内，就等于没分。
  2. 为什么「金钱」不能和「体力」放一组？
    体力每周回满，金钱只增不减。把节奏相反的数放一起，玩家会误判「钱也会掉」。

顺带说一句「结周」

你圈的第三个地方是那个灰掉的结周按钮。它现在的问题是：它看起来像一块空地——灰字、细边框、没有说明。 「没排满不能点」这句话缩成了 11px 的小字，还压在按钮里。

禁用态不该只靠变灰。要么把原因写在按钮外面（可见、够大），要么把按钮做得像「下一步」，点下去告诉你缺什么。这条不是间距问题，是第 3 课的内容，先记着。

作业（十五分钟）

  • 把你截图里那一行的五项，按你自己认可的方式分成三组，写下每组凭什么归在一起。
  • 给每组一个「节奏」：每周变 / 每年变 / 只增不减。
  • 不用改代码。分组定不下来，改 CSS 是白改。
