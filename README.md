# LPL 生涯模拟 · P2 可玩骨架

手机竖屏、可离线运行的单页原型：三个行动点 → 抽事件 → 比赛 → 结周存档。
目标不是好玩，是**可验证**。

## 跑起来

```bash
pnpm install          # 首次
pnpm dev              # 开发预览
pnpm build            # 产出 dist/index.html（单个文件，零外链）
pnpm test             # 规则核心单测
```

构建产物 `dist/index.html` 直接传给平台即可，不依赖任何外部资源。

## 三个目录，三层职责

| 路径 | 职责 | 不许做什么 |
|---|---|---|
| `src/core/` | 规则核心，纯函数 `reduce(状态, 动作) → { 新状态, 日志 }` | 不读界面、不碰存储、不自己取随机数 |
| `src/ui/` | 只做三件事：画状态、收集点击、把动作交给核心 | 不含任何数值规则 |
| `src/core/save.ts` | 只做「状态 ↔ 本地字符串」 | 不做规则判断 |

`src/config.ts` 是**唯一**该改数值的地方。调手感只动它。

`src/data/events.ts` 是事件库（当前 3 个事件 + 2 个填充事件，正文上限 50 字）。

## 怎么验证

```bash
node node_modules/vite-node/vite-node.mjs scripts/batch.ts 1000   # 1000 局批量统计
node scripts/smoke.mjs                                             # 真浏览器点一遍（需先 build）
```

批量脚本会输出结局类型分布、巅峰年份、六维区间——调参后跑一次就能看到变化。

## 已经能做的事

- 六维（操作/对线/团战/意识/心态/人气）、体力、段位、金钱、伤病、教练信任
- 八种行动；未签约时训练赛与商业活动锁定；体力不够的行动点只能休息，休息是唯一补给
- 事件：必触发 → 阶段分桶 → 条件过滤 → 权重（特殊:常规 = 1:10）→ 填充池
- 比赛：签约后才能打；有事件用选项结算，没事件自动结算；教练信任与伤病有硬阈值
- 成长：整数经验 + 递增阈值 + 年度涨幅上限；18–19 成长 / 20–23 巅峰 / 24–25 衰退
- 结局：普通（8 年到期 / 主动退役）与特殊（连续两个签约窗口无人可签）
- 存档：localStorage 单槽位、带版本号、临场值不进存档；存档以比赛周为界
- 同种子完全可复现

## 还没做（原型范围外）

- 美术、音效、动效
- 反馈池正式文案（现在只有占位句）
- 真实数值：所有数字都是占位，靠试玩调
- 签约、首秀、退役还是静默判定，没做成必触发事件
- 荣誉系统只做了 S 赛冠军、最佳新秀、名人堂判定；MVP / 最佳阵容未接
- 场外经济（赞助、资源）未接
- 多存档位、读档
