# 电竞选手模拟器

手机竖屏、单文件、可离线运行的 LPL 生涯模拟原型：**每周三个行动点 → 抽一个事件 → 打一场比赛 → 结周存档**，从 18 岁路人打到退役。

> **状态：可玩原型 P3。数值调优未验证。**
> 规则跑得通，胜负、段位、训练成本都能算；但手感、节奏、难度曲线还没有真人验证过。这里的数字随时会改。

## 直接玩

仓库里放的是 **P3 切片版**：`dist-slice/index.html`（单个 HTML，零外链、零后端，双击即可，也可手机浏览器打开）。

切片版 = 完整代码 + 一个编译期常量 `__SLICE_AT__ = 8`：打到第 8 周、春决打完就收尾，出一页「切片到此为止」。

想要八年完整版，自己构建：

```bash
npm run build        # 完整版 → dist/index.html
npm run build:slice  # 切片版 → dist-slice/index.html
```

## 四个页面

| 页签 | 内容 |
|---|---|
| 本周 | 六维、体力、段位与名次、人气、金钱、伤病、教练信任；三个行动格 |
| 赛程 | 联赛积分榜（第几名 / 14 支）、下一场对手、之后四周、当前阵容五人实力 |
| 生涯 | 六维当前值 + 荣誉柜（按年份分组，只显示已获得的） |
| 收支 | 本周/上周流水、余额、商店八项 |

## 跑起来

```bash
npm install       # 首次
npm run dev       # 开发预览
npm run build     # 产出 dist/index.html（单文件，零外链）
npm test          # 规则核心单测（61 条）
npm run smoke     # 真浏览器跑一周（Edge 无头，22 项）
```

## 三层职责

| 路径 | 职责 | 不许做什么 |
|---|---|---|
| `src/core/` | 规则核心，纯函数 `reduce(状态, 动作) → { 新状态, 日志 }` | 不读界面、不碰存储、不自己取随机数 |
| `src/ui/` | 只做三件事：画状态、收集点击、把动作交给核心 | 不含任何数值规则 |
| `src/core/save.ts` | 只做「状态 ↔ 本地字符串」 | 不做规则判断 |

`src/config.ts` 是**唯一**该改数值的地方。`src/data/` 放事件库、决赛与邀请、赛季名单。

## 数值一览（会变）

- **训练收益固定 1 点**（专训 2 点），**成本随属性递增**：`基础价 + 3 × ⌊(属性 − 40) ÷ 10⌋`
- 上分 14 起 / 专训 12 起 / 复盘 8 起 / 训练赛 16 起；健身 8、直播 10、商业 25
- **休息恢复 = 当前体力上限 × 25%**；体力上限初始 100，健身每次 +4
- 段位 = 分数 + 名次双门槛（王者要前 200 名，宗师前 600）
- 比赛胜负 = `0.5 + (我方五人均值 − 对手强度) ÷ 50 + 选项加成`，夹 5%–95%
- 生涯：18 岁起 8 年，每年 30 周；成长 2 年 / 巅峰 4 年 / 衰退 2 年

## 已知未完成

- 对手强度 60/65/70/78 是占位，没有「对手能力表」
- 联赛只有决赛事件，常规赛对手不区分强弱
- MSI / 常规赛 MVP / 最佳阵容 / 名人堂还没有写入代码
- 事件引擎没有「跨周记忆」（写不出「连续两周没上场」）
- 反馈池每行动只有 5 句，日志窗口只有 6 条
- 全真名真队名：与平台「无侵权风险」条款存在冲突，风险自负
