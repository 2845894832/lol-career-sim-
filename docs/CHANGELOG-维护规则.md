# 更新日志维护规则

**每次更新版本，同时更新日志。** 日志没写，不算发完。

1. **谁写**：AI 每次改完只说一句「这版要不要记、记什么」，条目与版本号由你拍板——AI 不替你定。
2. **什么时候**：发版当天写。平时改动先挂在 `CHANGELOG.md` 的 `[Unreleased]` 下，没发版的不写版本号。
3. **写进哪**：`CHANGELOG.md` 写一版一行的对外摘要（给仓库和 agent 读）；详细说明、已知未修表、存档对照写 `docs/6.4-更新日志.docx`（给人读）。版本条目冲突时以 `CHANGELOG.md` 为准。
4. **格式三条**：①一条一句，只写玩家看得见的变化，不写内部重构；②必带「影响谁」（全体 / 已存档玩家 / 切片版玩家）与「重跑什么」；③版本号与 `package.json` 对齐，只有存档结构变了才动 `CONFIG.version`。
