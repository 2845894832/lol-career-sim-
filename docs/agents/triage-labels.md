# Triage 标签

技能按五个标准分诊角色说话。本文件把角色映射到本仓库实际使用的标签字符串。

| 技能里的角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent 做 |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不做 |

技能提到某个角色时（例如「打上 AFK-ready 分诊标签」），用上表对应的字符串。要换词表就改「本仓库的标签」这一列。
