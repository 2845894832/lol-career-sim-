# 0013 · 性能预算不测真机，六条线不动

- 状态：已定
- 日期：2026-11-05
- 出处：用户原话「不测」「不动」（2026-11-05，回答 ticket 20 的两问）
- 待确认项：帧率、白屏/崩溃、手机端表现这三项仍「未测」，没有任何数据

## 背景

`docs/3.4-性能预算.docx` 定了六条硬预算（包体 ≤150 KB、首屏 ≤1.0 s、操作响应 ≤100 ms、内存 ≤80 MB、帧率 ≥50 fps、网络请求 0）。第 20 号 ticket 用本机 PC + Edge 无头（390×844，`file://` 打开 `dist/index.html`）实测了一遍，唯一没被打脸的是「全都远在线内」，但没有一项来自手机。

## 决定

1. **不为性能专门上真机**，也不借 09 号真机测试顺手量。
2. 六条预算线**一条不改**（150 KB / 1.0 s / 100 ms / 80 MB / 50 fps / 0 请求）。
3. 发布依据 = 本机 PC 的实测数据（包体 88.5 KB、构建 2.62 s、首屏 14–18 ms、点击到画面 0.5–0.9 ms、`placementOf()` 中位 1.68 ms、JS 堆 1.9–3.9 MB）。

## 考虑过的替代方案

① 借 09 号真机测试顺手量（约 10 分钟）：被否，理由是性能不是当前瓶颈，真机时间留给「能不能玩完」。
② 单独一轮真机性能测试（半天）：同上，收益不足以抵消。
③ 收紧/放宽包体线：被否，150 KB 之外没有依据支撑新数字。

## 后果

- 手机端卡不卡、会不会白屏，**发布前不会有答案**；只能靠投稿后玩家反馈。
- 若手机端真的卡，问题多半落在 `placementOf()`（10000 个虚拟对手 × 每次结算）与首屏解析，改法已在 3.4 的「砍序」里写好。
- 3.4 第 2–6 项保持「未测」，不再补测。
