# 0012 · 零位图、零音频

- 状态：已定
- 日期：2026-11-04（回填；决定实际做出于 2026-10-28 ~ 11-04 的会话中）

## 背景

单文件要可离线、要 ≤150 KB；图片和音频是最容易破坏这两条的东西。

## 决定

界面全部用 CSS + 文本；战绩卡用纯文本四行，不生成图片。

## 考虑过的替代方案

① 一两张封面图（+30–200 KB，且要处理路径内联）② 音效（破坏静音场景与包体）

## 后果

视觉只能靠排版、颜色与数字，审美上限被锁；换来的是任何设备都能秒开。
