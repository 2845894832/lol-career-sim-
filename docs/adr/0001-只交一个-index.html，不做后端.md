## 背景

目标平台是虎扑 AI 工坊，玩家点链接就能玩。没有服务器、没有账号体系、没有运维预算。

## 决定

单文件纯前端：所有 JS/CSS 内联，零外链、零请求、零后端，可离线。

## 考虑过的替代方案

① 静态托管 + 多文件（多几次请求，平台可能只收单文件）② 小型后端存进度（要运维，不做）

## 后果

所有状态只能放 localStorage；换设备无法同步。换来的是「双击就能玩」和投稿零门槛。

## 证据

产物 `dist/index.html` 88.5 KB、`dist-slice/index.html` 89.3 KB，Network 面板 0 请求。
