# 0003 · 段位只影响签约，不影响胜负

- 状态：已定
- 日期：2026-11-04（回填；决定实际做出于 2026-10-28 ~ 11-04 的会话中）
- 出处：用户原话 · 2026-10-31 20:26「事件里只用六维和人气，段位不参与概率。段位只决定『能不能签约』」（T132）；4500 门槛见 10-30 21:49「王者门槛4500」（T123）

## 背景

段位如果直接加战力，会变成「刷分游戏」，而不是生涯模拟。

## 决定

段位（LP）只决定能不能进队（王者档 4500 分 + 名次前 200）；比赛胜负只由六维与队伍实力决定。

## 考虑过的替代方案

① 段位给胜率加成（会让刷分成为最优解）② 段位完全无用（签约就没有门槛）

## 后果

签约是唯一的一次「段位变现」，所以签约窗口必须早出现，否则前期刷分没反馈。

## 证据

`CONFIG.rank.kingGate = 4500`；`winChance` 里没有任何 LP 项。
