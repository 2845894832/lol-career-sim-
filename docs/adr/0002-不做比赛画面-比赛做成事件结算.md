# 0002 · 不做比赛画面，比赛 = 一次事件结算

- 状态：已定
- 日期：2026-11-04（回填；决定实际做出于 2026-10-28 ~ 11-04 的会话中）
- 出处：用户原话 · 2026-10-28 22:03「我们可以把比赛做成事件,为了节省暂时不必要的工作量,不用处理经济、技能、AI、平衡」（T22）

## 背景

一局 1–1.5 小时、240 周，每周都画一场比赛不可能；也没有美术与音频预算。

## 决定

比赛做成「按胜率摇一次色子 + 一段文字结果」，不做逐帧画面、不做 BP、不做选手操作。

## 考虑过的替代方案

① 2D 简笔画比赛（至少 +40h 工时）② 外部跳转看录像（破坏单文件）

## 后果

爽点从「操作」转移到「读战报 + 做选择」。这也决定了事件文本必须够好笑。

## 证据

`src/core/league.ts:175` 一次 `winChance` 计算即出一场结果。
