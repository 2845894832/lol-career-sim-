# 0006 · 休息按体力上限的 25% 恢复，不按固定值

- 状态：已定
- 日期：2026-11-04（回填；决定实际做出于 2026-10-28 ~ 11-04 的会话中）
- 出处：用户原话 · 2026-11-04 20:01「把休息改为25%」（T252）

## 背景

按固定值回体力时，后期上限涨了，休息就变成废格；不休息又打不动。

## 决定

`rest.restoreRatio = 0.25`，恢复量 = 当前上限 × 25%；基础价 0。

## 考虑过的替代方案

① 固定 20 点（后期废）② 回满（一周回满，节奏太快）

## 后果

体力上限越高，休息收益越大 → 健身的价值被放大，这是「健身速通」漏洞的根。

## 证据

`CONFIG.actions.rest = { stamina: 0, restoreRatio: 0.25 }`，提交 `5db0515`。
