# 0007 · 行动成本随属性递增，收益固定 1 点

- 状态：已定
- 日期：2026-11-04（回填；决定实际做出于 2026-10-28 ~ 11-04 的会话中）

## 背景

固定成本 + 分段收益（3/2/1）时，前期刷得太快、后期收益又骤降，曲线很难看。

## 决定

成本 `基础价 + 3 × ⌊max(0, 属性 − 40) / 10⌋`；收益一律 +1（专训 +2，同维）。

## 考虑过的替代方案

① 收益递减（3/2/1，被否定）② 成本固定（后期闭眼刷）

## 后果

属性 100 时上分成本 32 体力，一周三格几乎打不满 → 后期被迫做取舍。这正是想要的。

## 证据

`CONFIG.actions.cost = { from: 40, step: 3 }`、`trainGain: 1`，提交 `275dcbf`。
