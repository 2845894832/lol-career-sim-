# 0008 · 比赛只给信任/人气/荣誉，不给属性

- 状态：已定
- 日期：2026-11-04（回填；种类决定实际做出于 2026-10-28 ~ 11-04 的会话中）；数值与伤病事件化 2026-11-05 定
- 出处：用户裁定 · 2026-11-05「采用,更新」（+2/−4 与伤病事件化，见 ticket 03）
- 待确认项：E05 两个选项的 ±2 信任 / ∓5 体力是落地初版，用户没有逐项表过态；不影响 +2/−4

## 背景

开发中曾把「比赛胜利 +1 操作」写进规则，但用户从未批准过这条。

## 决定

赢：教练信任 +2、人气 +1、决赛记荣誉；输：信任 −4；输球 12% 概率挂「手腕不适」标记，下周由事件 E05 结算伤病（+1）。**没有任何属性变动。**

## 状态变更

- 2026-11-05：用户指出这些奖励他没有决定过（原话：「我并没有决定这些」），本条状态从「已定」改为「待确认」，见 `.scratch/22点决策地图/issues/03-比赛到底给什么.md`。
- 2026-11-05：同一天用户指示「把待确认改成已定」，状态改回「已定」。正文与数值自始至终未改，这两次变更都留在这里。
- 2026-11-05：用户回「采用,更新」——赢信任从 +3 改为 +2，输仍 −4；伤病从「12% 当场 +1」改为「12% 挂标记，下周 E05 事件结算」。状态保持「已定」。

## 考虑过的替代方案

① 比赛给属性（用户明确否认：「这是什么时候的规定」）
② 赢 +3 / 输 −4 / 12% 当场加伤（03 号材料里的「甲」，未采用）
③ 赢 +5 / 输 −2（03 号材料里的「乙」，未采用）
④ 去掉随机伤病、改固定条件（03 号材料里的「丙」，未采用）

## 后果

属性只能靠每周三格训练获得，节奏被锁死；比赛的价值全在「信任」这条暗线上。

+2/−4 的正常玩模拟与 +3/−4 几乎同场次，只把前两年信任压低约 5–6 点；真正决定信任的是训练赛每周 +2 和胜率。伤病事件化不改变频率（正常玩约 3.4 次/8 年、因伤缺约 0.8 周），改变的是可见性：从「隐藏掷骰」变成「下周一张必须二选一的卡」。
